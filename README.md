# We Paint Siding

Next.js company website for exterior and interior painting across Southern Ontario.

## Development

Use Node.js 24. Install dependencies with `npm ci`, start development with `npm run dev`, and build production with `npm run build -- --webpack`. Run production locally with `npm start`. The GitHub main branch deploys to Vercel.

## Current design and source

- `app/components/approved-homepage.js` and `app/approved-homepage.css`: current homepage.
- `app/components/site-chrome.js` and `app/site-chrome.css`: shared responsive header, service and area menus, original logo, and footer.
- About, contact, main services, locations, work and FAQ routes use their local page components and stylesheets.
- `app/components/exterior-service-page.js` and `app/components/interior-detail-page.js`: current exterior and interior sub-service layouts. Their template data, local stylesheets and enquiry components are retained; shared service helpers remain available for other pages.
- `app/data/service-pages.js`: service content; `exterior-template-content.json` and `interior-template-content.json`: current template content; `service-media.json`: image assignments; `service-meta-titles.json`: retained title updates.
- `app/components/main-service-schema.js`: main-service structured data. Sub-service schema is generated by the shared template.
- `app/support/page-shell.js` and `app/support/editorial.css`: blog and supporting page design.
- `app/components/area-map.js`: responsive Google Maps embeds for service areas.
- `app/components/site-effects.js` and `app/site-effects.css`: shared interaction and reduced-motion handling.

Exterior Painting and Interior Painting are the two main services. Interior sub-services are Basement, Cabinet, Trim, Door, Wall and Ceiling Painting. Redirects for retired URLs are preserved in `next.config.mjs`.

## Images and data

Keep current photographs, service image assignments, company-photo metadata and source records. Company images and generated illustrative images are distinct; preserve existing captions and descriptions. Images are under `public/images`, with licensed local fonts under `public/fonts`.

## Forms

Project forms validate input and export a local draft ZIP with photos. They do not send enquiries online. Preserve the visible draft notices unless a real delivery backend is implemented.

## Verification

Run `npm run build -- --webpack`, followed by `python scripts/check-service-pages.py`. The audit checks the current sub-service routes, headings, metadata, structured data, form labels, image files, links, FAQs and sitemap coverage. Build and source checks do not replace browser or real-device testing.

## Maintenance

Keep shared CSS until all consuming routes have been checked: several global stylesheets still support active pages. Retired design components, unimported stylesheets, obsolete mockup assets and superseded design notes have been removed. Previous versions remain recoverable through Git history.
