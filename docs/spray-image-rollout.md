# Spray-painting image rollout

The current layouts, CSS, copy and finished-property photographs are retained. Legacy application images are resolved centrally through `CompanyImage`; the replacement map also updates alternative text, dimensions and generated-image provenance. Original uploaded company photographs are retained in the asset archive rather than overwritten with generated content.

## New generated assets

Built-in image generation was used. Every prompt requested a 1536 × 1024 photorealistic editorial scene, realistic hose-fed airless equipment, controlled spray, protected adjacent surfaces and suitable protective equipment; no brushes, rollers, logos, text or watermarks. The final optimized files are in `public/images/spray/`.
