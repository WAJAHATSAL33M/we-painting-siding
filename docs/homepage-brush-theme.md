# Approved brush homepage theme

Applies the reviewed desktop/mobile brush mockups to the existing homepage without changing its service hierarchy, section content, company logo, images, destination routes or draft-only quote behavior. The last hero mockup is the reference: mobile copy and calls to action precede the photo.

Six self-hosted SVG masks embed lossless alpha silhouettes derived from the approved mockup artwork itself: broad paint bands, tapered underlines, rough section transitions, left/right photo reveals, and bottom photo edges. They are decorative CSS surfaces with no semantic content or interactive hit area. Text and controls remain outside masking. The real regional map keeps its normal controls and attribution.

The visual update covers the hero, assurance strip, service image edges, before/after boundaries and adjacent project selectors, exterior photo ribbon, interior/cabinet panels, process commitment seam, company imagery and philosophy band, map surround, guide strip, quote transition and footer headings. The project selector retains its same three projects and functionality. Mobile texture heights, photo edges, type sizes and button layouts use explicit 760px and small-phone adjustments.

Validation: production build generates all 62 routes; DOM interaction checks pass for navigation/Escape/focus, range comparison, project switching, location filtering/map focus, service presets and draft download. Prerendered links and image assets are verified. SVG XML parses and raster previews were inspected. Live browser review is part of the publishing check. Reference-derived silhouettes replace procedural strand paths; photo captions remain outside masks. Exact responsive pixel equivalence is not asserted.
